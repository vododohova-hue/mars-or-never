# Марс или никогда

Ретро 8-битный скролл-шутер с элементами менеджмента. Илон летит на Марс на Starship: топливо ограничено, каждое препятствие можно сбить, облететь или купить. Долетишь с хайпом 70+ — станешь легендой. Не долетишь — станешь мемом.

**Играть:** https://vododohova-hue.github.io/mars-or-never/

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | Полёт |
| Пробел / Z | Огонь (тратит топливо) |
| Shift / X | Форсаж (тратит топливо, даёт хайп) |
| B | Заплатить за ближайшее препятствие |
| R | Ремонт корпуса ($60) |
| T | Твитнуть (риск!) |
| P | Пауза |
| M | Звук |

Один файл `index.html`: HTML5 Canvas и чистый JavaScript, без библиотек и внешних картинок, работает офлайн.
